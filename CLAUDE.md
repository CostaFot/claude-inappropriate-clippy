# claude-inappropriate-clippy

Inappropriate Clippy as a Claude Code mod: a plugin whose hooks module draws him in the
band above the prompt (`AbovePrompt`) and reacts to tool calls, prompts and turns. The
Omarchy bar version is `~/Work/omarchy-inappropriate-clippy`; its `quotes.json` and
sprite atlas are the source of the lines and frames here.

Local only until Costa says otherwise. Creating the GitHub repo, pushing, and
publishing to a marketplace or the Claude plugin directory all wait for his go.

## Layout

- `hooks/register.tsx`: every hook, the band, slap/kill/revive, Haiku, leaderboard.
- `hooks/rules.ts`: what he reacts to, with the fallback lines.
- `hooks/sprite.ts`: an animation as an SVG (frame strip stepped by SMIL).
- `hooks/book.ts`, `hooks/sprites.ts`, `hooks/sprites/`: generated by
  `scripts/build-assets.mjs` from the Omarchy repo. Needs `magick`. Never hand-edit.
- `types/index.d.ts`: the `$.state` contract. `tests/`: `claude plugin test` files.

## Commands

```bash
claude plugin validate .      # what the engine would refuse
claude plugin test .          # tests/*.test.ts
node scripts/build-assets.mjs # regenerate the book and sprites
```

`tsc -p .` type-checks against the types the engine lays in `.claude-plugin/types/`
on load. TypeScript is not installed on this machine.

To run it from a session: load the `plugin-authoring` skill and symlink this folder
into that session's `~/.claude/dev-mods/<session>/`. Edits hot-reload when a turn ends.

## Gotchas

- The engine reads no module file over 1 MiB, so each animation is its own file.
- Any function handed `$` must be declared at the module's top level, or validate
  refuses it. Module state lives in `s` and `opts` for that reason.
- On the desktop, an `Svg` with `isInteractive` draws nothing for an embedded
  `data:` PNG. Plain image mode draws it, and SMIL still plays there.
- Tests run with nothing beneath the plugin: `host()` in the test file answers
  `session.start`, `command.register`, `audio.play`, `ui.toast`, `ui.render` and the store.
- Hooks only watch tool calls: they pass the call on untouched and return its result.
- Respawn and revive both go through `s.deathTimer`, so a revive cancels the pending respawn.
- `claude plugin validate` warns that `CLAUDE.md` at the plugin root is not loaded as
  context. Expected.
